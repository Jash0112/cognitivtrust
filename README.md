# CognitiveTrust: A VS Code Security Assistant

![Security Check Icon](https://via.placeholder.com/728x90.png?text=CognitiveTrust+Security+Scanner)

CognitiveTrust is a Visual Studio Code extension that acts as a real-time security assistant for developers. It helps identify and fix common insecure coding patterns as you write code, with a special focus on securing code generated by AI tools.

## Key Features

- Real-time Security Scanning: Automatically scans your Python and `requirements.txt` files on save.
- Three Types of Detection:
    - Hardcoded Secrets: Finds API keys, passwords, and other credentials exposed in your code.
    - Missing Authorization: Detects Flask routes that may be missing security checks.
    - Outdated Libraries: Checks your `requirements.txt` for known vulnerable library versions.
- One-Click Fixes: Provides "Quick Fix" suggestions to automatically resolve detected issues.
- AI-Powered Refactoring: Uses the OpenAI API to offer experimental, intelligent code refactoring for security issues.
- Workspace-Wide Scanning: A command to scan all files in your project at once.
- Metrics Tracking: Keeps a count of how many fixes you've applied.

## Installation

1.  Prerequisites: Make sure you have [Node.js](https://nodejs.org/) and [Semgrep](https://semgrep.dev/docs/getting-started/) installed and available in your system's PATH.
2.  Clone the Repository: `git clone <your-repo-url>`
3.  Install Dependencies: `cd cognitivtrust` and run `npm install`.
4.  Run the Extension:
    - Open the project in VS Code.
    - Press F5 to start the "Extension Development Host" window.
    - Open a Python project in the new window to start using the extension.

## Usage

### Automatic Scanning
Simply save a `.py` file or a `requirements.txt` file. The extension will automatically scan it and display any findings as warning or error lines.

### Using Quick Fixes
When you see a warning (a squiggly line), click on the line. A lightbulb icon will appear. Click the lightbulb to see the available one-click fixes, such as:
- "Replace with environment variable"
- "Upgrade <library> to secure version"
- "Refactor with AI (Experimental)"

### Commands
Open the command palette (Ctrl+Shift+P) and type "CognitiveTrust" to see all available commands:
- CognitiveTrust: Scan Entire Workspace: Scans all files in your project folder.
- CognitiveTrust: Show Fix Statistics: Displays a message with the total number of fixes applied.

### Configuring the OpenAI API
To use the "Refactor with AI" feature, you must add your OpenAI API key to your VS Code settings:
1.  Go to File > Preferences > Settings.
2.  Click the "Open Settings (JSON)" icon in the top right.
3.  Add the following line:
    ```json
    "cognitivtrust.openai.apiKey": "sk-YourSecretApiKeyGoesHere"
    ```
